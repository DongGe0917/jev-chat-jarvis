# Jev 聊天助手 (JevChat) - v1.3 Enhanced

**装在手机上的「高情商对话副驾」：你在任何聊天 App 里聊天，它在旁边读懂对方心理意图、评估冲突危险度、给出高情商回复建议，一键填进输入框，发不发完全由你决定。**

已在 **微信、QQ、X（Twitter 私信）** 三个平台真机跑通。非侵入式设计，不改包、不 hook、不读本地数据库。

---

## 🌟 v1.3 核心升级特性

- 🌐 **Cherry Studio 风格多服务商直连**：告别仅支持 OpenRouter 的限制，原生支持 **DeepSeek**、**OpenAI**、**硅基流动 (SiliconFlow)**、**月之暗面 (Moonshot / Kimi)**、**智谱 AI (GLM)** 及 **自定义 API (OneAPI/Ollama)**。
  - 各服务商的 API Key、Base URL 与 Model 独立持久化存储，自由切换无需重新输入。
  - 设置页面内置实时网络延迟与意图研判连通性测试。
- 🧠 **深度内置 Jev 7 大心理研判内核**：将原版经多轮标定校准的核心规则提取并深度注入为通用 Prompt，国内大模型直连亦可实现高精度心理研判：
  - **潜台词识别**：精准区分“在乎度/忠诚试探”（如“那你最好是”、“大忙人”、“随便你”）与普通日常诉求。
  - **10 级冲突阶梯危险等级**（0~9 分分档预警）。
  - **行动策略决断**：被质问时第一优先级强制为“翻看聊天记录确认事实”，严禁瞎猜或假道歉。
  - **口语化字数硬约束**：起草回复严格限制在 **5~35 字**，杜绝假大空公文风。
- 🎭 **回复风格与人设定制**：新增人设配置区，支持自由输入人设 Prompt，并提供预设一键切换：
  - `日常自然`（默认） / `幽默机智` / `温柔暖心` / `职场严谨` / `简短克制`。
- ⚡ **彻底消除悬浮窗卡顿与开合失灵**：
  - **重构手势判定**：改用系统级 `ViewConfiguration.scaledTouchSlop` 区分轻触与拖拽，彻底解决手指轻微位移被误判为拖拽而吞掉点击事件的问题。
  - **无障碍事件 300ms 智能防抖节流**：对微信界面内容变动与滚动事件合并降频，释放主线程压力，杜绝微信界面掉帧与卡顿。
  - **即时交互反馈**：悬浮球按下微缩放动效，拖拽时即时注销长按监听。

## 💡 产品亮点

- **非侵入式安全设计**：不 hook、不改包、不走任何 App 的账号接口、不读本地数据库，仅通过系统无障碍服务读取「当前屏幕显示的对话内容」。
- **心理学深度研判**：实时解析对方真实意图、冲突危险等级（0~9 分）、心理诉求、行动策略与把握度。
- **3 条候选回复智能排序**：结合当前会话人设与心理研判，生成 3 条风格互补的短口语回复，并给出推荐占比。
- **发送永远由你把控**：程序只将选中的候选内容填入输入框，绝不自动发送，绝不触碰转账、红包或敏感按键。
- **隐私保护在本地**：API 密钥仅保存在 App 私有存储，对话内容仅在主动点击分析时发送给对应模型端点，绝不落盘、不存云端。

## 📱 平台支持与采集原理

| 平台 | 状态 | 采集方式 | 技术实现说明 |
|---|---|---|---|
| **微信 Android** | ✅ 全链路 | 伪装系统无障碍服务读取气泡节点 | 适配微信 8.0.52+ 混淆节点，通过伪装系统 SelectToSpeak 读 `id/bkl` 气泡，按左右位置判定收发方 |
| **手机 QQ** | ✅ 全链路 | 无障碍节点解析 | 开放节点架构，解析正文 `id/mjn`、标题 `id/371`，按气泡贴近头像列计算收发方 |
| **X (Twitter) 私信** | ✅ 全链路 | Compose UI content-desc 语义解析 | 解析 Compose 节点 content-desc（`发件人：正文。时间。Read`），通过 EditText 存在性判断聊天窗 |
| **飞书 / Lark** | 🟡 部分支持 | 无障碍读取框架信息 | 正文为自绘控件，可读取标题、气泡位置与输入框，后续规划截屏 OCR 兜底 |

## 🚀 快速上手

### 1. 下载安装
- **GitHub Releases 下载**：[v1.3 Release 下载页面](https://github.com/DongGe0917/jev-chat-jarvis/releases/tag/v1.3)
- **本地仓库预编译包**：[`apk/jev-assistant-v1.3-debug.apk`](apk/jev-assistant-v1.3-debug.apk)

```bash
adb install -r apk/jev-assistant-v1.3-debug.apk
```

### 2. 配置模型服务商
1. 打开 **Jev 聊天助手** App，进入「设置」；
2. 选择你需要使用的模型平台（如 **DeepSeek**、**硅基流动**、**OpenAI**、**月之暗面**、**智谱 AI** 或 **自定义 API**）；
3. 填入你的 API Key（如果选用官方 DeepSeek，填入 `sk-...`，模型默认为 `deepseek-chat`）；
4. 选择你偏好的**回复人设风格**（如「日常自然」或「幽默机智」）；
5. 点击下方**「测试连通性」**，确认模型网络连接与意图识别解析正常。

### 3. 授予必要权限
按主页面向导依次开启：
1. **无障碍服务**：用于读取聊天界面的对话气泡；
2. **悬浮窗权限**：用于在聊天应用上层展示悬浮球与分析面板；
3. **后台保活 / 电池无限制**：避免系统杀后台（特别是小米 HyperOS / 华为等系统，建议开启自启动与省电无限制）。

### 4. 开始使用
打开微信、QQ 或 X，进入任意聊天界面，即可看到屏幕侧边的 Jev 悬浮球。点击悬浮球即可呼出实时研判面板与候选回复，点击任意候选词即可快速填入输入框！

## 💻 源码构建与测试

### 环境需求
- JDK 17+
- Android SDK (Platform 35, Build Tools 35)

### 编译 APK
```bash
# 编译 Debug 版 APK
./gradlew assembleDebug

# 产物路径：app/build/outputs/apk/debug/app-debug.apk
```

### 运行自动化单元测试
本项目包含完整的轻量 Mock Server 接口测试套件：
```bash
./gradlew testDebugUnitTest
```
测试内容涵盖多服务商配置映射、Mock 响应解析、Markdown 净化、错误码友好提示及提示词生成，保证核心逻辑 100% 可用。
