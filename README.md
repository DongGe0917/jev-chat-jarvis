# Jev 聊天助手 (JevChat) - v1.5 双引擎版 (Dual-Engine)

**装在手机上的「高情商对话副驾」：你在任何聊天 App 里聊天，它在旁边读懂对方心理意图、评估冲突危险度、给出高情商回复建议，一键填进输入框，发不发完全由你决定。**

已在 **微信、QQ、X（Twitter 私信）** 三个平台真机跑通。非侵入式设计，不改包、不 hook、不读本地数据库。

---

## 🌟 v1.5 核心升级特性 (最新发布)

- 🚀 **双引擎协同架构深度重构 (文本起草 + Jev 研判解耦)**：
  - **引擎 A【AI 文本补全服务】**：由上游大模型（如 DeepSeek、OpenAI、硅基流动等）专注负责上下文理解，起草 3 条自然地道的微信口语短句。
  - **引擎 B【TypeSafe Jev 官方心理研判】**：原生直连 TypeSafe Jev 官方端点（`https://api.typesafe.ai/v1/systemone`，模型 `jev-latest`），执行 7 维度心理研判与候选回复概率胜率打分排序。
- ⚡ **双网络连接测试与实时延时显示**：
  - 设置页面提供独立的**「测试文本补全连接」**与**「测试 Jev 研判连接」**两个测活按钮，真实发起请求并毫秒级精确展示网络延迟（如 `916ms` / `491ms`）。
- 🛡️ **彻底解决 Cloudflare 拦截阻断**：
  - 底层网络层全面注入现代标准浏览器客户端标识（User-Agent），彻底解决官方接口因缺少请求头被 Cloudflare 拦截返回 HTTP 403 (Error 1010) 的问题。
- 📱 **设置界面双卡片式重构与版本显式化**：
  - 卡片 1（文本补全）+ 卡片 2（Jev 研判）分工明晰；
  - 界面顶部标题与底部页脚均动态展示当前运行版本号（`v1.5 Build 5`），杜绝安装版本混淆。
- 🌐 **Cherry Studio 风格多服务商直连**：支持 **DeepSeek**、**OpenAI**、**硅基流动 (SiliconFlow)**、**月之暗面 (Moonshot / Kimi)**、**智谱 AI (GLM)** 及 **自定义 API (OneAPI/Ollama)**，各平台密钥与端点独立保存。
- 🧠 **内置 Jev 7 大心理研判准则**：潜台词识别、10 级冲突阶梯危险等级、行动策略优先翻查记录、5~35 字真实口语约束。
- 🎭 **回复风格与人设定制**：提供自定义 Prompt 与预设快捷标签（日常自然、幽默机智、温柔暖心、职场严谨、简短克制）。
- ⚡ **无障碍防抖与悬浮球流畅触控**：系统级 TouchSlop 手势识别 + 300ms 智能节流，彻底杜绝微信卡顿。

## 💡 产品亮点

- **非侵入式安全设计**：不 hook、不改包、不走任何 App 的账号接口、不读本地数据库，仅通过系统无障碍服务读取「当前屏幕显示的对话内容」。
- **心理学深度研判**：实时解析对方真实意图、冲突危险等级（0~9 分）、心理诉求、行动策略与把握度。
- **3 条候选回复智能排序**：结合当前会话人设与心理研判，生成 3 条风格互补的短口语回复，并给出推荐占比。
- **发送永远由你把控**：程序只将选中的候选内容填入输入框，绝不自动发送，绝不触碰转账、红包或敏感按键。
- **隐私保护在本地**：API 密钥仅保存在 App 私有存储，对话内容仅在主动点击分析时发送给对应模型端点，绝不落盘、不存云端。

## 📱 平台支持与采集原理

| 平台 | 状态 | 采集方式 | 技术实现说明 |
|---|---|---|---|
| **微信 Android** | ✅ 全链路 | 伪装系统无障碍服务读取气泡节点 | 适配微信 8.0.52+ 混淆节点，通过伪装系统 SelectToSpeak 读 `id/bkl` 气泡，按左右位置判定收发方 |
| **手机 QQ** | ✅ 全链路 | 无障碍节点解析 | 开放节点架构，解析正文 `id/mjn`、标题 `id/371`，按气泡贴近头像列计算收发方 |
| **X (Twitter) 私信** | ✅ 全链路 | Compose UI content-desc 语义解析 | 解析 Compose 节点 content-desc（`发件人：正文。时间。Read`），通过 EditText 存在性判断聊天窗 |
| **飞书 / Lark** | 🟡 部分支持 | 无障碍读取框架信息 | 正文为自绘控件，可读取标题、气泡位置与输入框，后续规划截屏 OCR 兜底 |

## 🚀 快速上手

### 1. 下载安装
- **GitHub Releases 下载**：[v1.5 Release 下载页面](https://github.com/DongGe0917/jev-chat-jarvis/releases/tag/v1.5)
- **本地仓库预编译包**：[`apk/jev-assistant-v1.5-debug.apk`](apk/jev-assistant-v1.5-debug.apk)

```bash
adb install -r apk/jev-assistant-v1.5-debug.apk
```

### 2. 配置双引擎服务商
1. 打开 **Jev 聊天助手** App，进入「设置」；
2. **配置文本补全服务**：选择大模型平台（如 **DeepSeek**、**硅基流动**、**OpenAI**、**月之暗面**、**智谱 AI** 或 **自定义 API**），填入 API Key，点击**「测试文本补全连接」**确认延时；
3. **配置 Jev 心理研判（推荐启用）**：开启 Jev 官方心理研判开关，填入 TypeSafe 官方提供的 `apikey_...`，点击**「测试 Jev 研判连接」**确认延时；
4. 选择你偏好的**回复人设风格**（如「日常自然」或「幽默机智」），点击最下方**「保存配置」**即可生效。

### 3. 授予必要权限
按主页面向导依次开启：
1. **无障碍服务**：用于读取聊天界面的对话气泡；
2. **悬浮窗权限**：用于在聊天应用上层展示悬浮球与分析面板；
3. **后台保活 / 电池无限制**：避免系统杀后台（特别是小米 HyperOS / 华为等系统，建议开启自启动与省电无限制）。

### 4. 开始使用
打开微信、QQ 或 X，进入任意聊天界面，即可看到屏幕侧边的 Jev 悬浮球。点击悬浮球即可呼出实时研判面板与候选回复，点击任意候选词即可快速填入输入框！

## 💻 源码构建与测试

### 环境需求
- JDK 17+
- Android SDK (Platform 35, Build Tools 35)

### 编译 APK
```bash
# 编译 Debug 版 APK
./gradlew assembleDebug

# 产物路径：app/build/outputs/apk/debug/app-debug.apk
```

### 运行自动化单元测试
本项目包含完整的轻量 Mock Server 接口测试套件：
```bash
./gradlew testDebugUnitTest
```
测试内容涵盖双引擎协同、多服务商配置映射、Mock 响应解析、Markdown 净化、错误码友好提示及提示词生成，保证核心逻辑 100% 可用。
